# rules-core

平台无关、无 I/O 的 TypeScript 规则核心垂直切片。当前支持：

- Draft 2020-12 内容 Schema 加载与校验；
- 地块旋转、边缘匹配和放置错误码；
- 道路、城市、田野连通组件；
- 普通随从和修道院长目标解析、已占用特征拒绝；
- 道路、城市、修道院、田野及终局计分；
- 并列全分、盾徽与修道院长召回；
- 规范序列化、SHA-256 状态指纹和纯函数重放。

在仓库根目录运行：

```bash
npm test
npm run typecheck
```

## 依赖说明

- `ajv`：唯一运行时依赖，用于执行仓库已有的 JSON Schema Draft 2020-12 契约；规则与计分逻辑本身不依赖第三方库。
- `typescript`、`@types/node`：仅用于构建与严格类型检查。
