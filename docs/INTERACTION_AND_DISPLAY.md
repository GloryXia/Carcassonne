# 交互与大屏设计

- 文档版本：0.1
- 主要场景：Windows + 4K 电视 + 玩家手机
- 设计原则：手机优先、公共与私人信息分离、操作可确认、无手机可降级

## 1. 设备角色

| 设备 | 主要职责 |
|---|---|
| Windows 主机 | 规则判定、持久化、房间管理、4K 渲染和降级操作 |
| 4K 电视 | 公共地图、公共计分、当前回合、事件和连接状态 |
| 玩家手机 | 当前地块、候选位置、角色选择、私人信息和确认操作 |

电视不显示秘密选择。手机不自行计算合法性或计分。

## 2. 聚会入口

Windows 首页提供：

- 创建局域网房间
- 继续未完成对局
- 单机对战 AI
- 规则与设备测试
- 未来的在线入口占位

创建局域网房间后，大屏显示：

- 二维码
- 短房间码
- 当前已加入玩家
- 网络与主机状态
- 使用 PC 直接加入的备用入口

目标是 60 秒内完成建房、加入和开局。

## 3. 手机加入流程

1. 扫描大屏二维码或输入局域网地址。
2. 选择已有本地档案或输入临时昵称。
3. 选择可用颜色和席位。
4. 等待房主批准。
5. 完成触控、网络和可选声音测试。
6. 点击准备。

首阶段不要求安装 App、注册账号或连接互联网。

## 4. 手机回合流程

### 4.1 抽取阶段

- 手机显示当前抽到的地块和可旋转的 3D 或 2D 预览。
- 大屏显示当前玩家、地块背面到正面的公共抽取动画。
- 非当前玩家只能看到规则允许公开的信息。

### 4.2 选择位置

- 大屏标出所有合法候选区域。
- 手机显示简化俯视地图、候选位置列表和最近候选。
- 点击手机上的候选位置后，大屏自动聚焦并显示半透明预览。
- 玩家可以使用左右旋转按钮切换合法方向。
- 手势可以作为快捷方式，但不得是唯一操作方式。

### 4.3 确认地块

- 手机显示相邻边缘匹配结果。
- 非法操作需要同时提供图形、文字和触觉提示。
- 玩家点击确认后，命令才提交给 Windows 主机。
- 主机验证成功后，大屏播放正式放置；失败时手机保留在预览状态并说明原因。

### 4.4 选择角色

- 手机显示刚放置地块上的合法角色区域。
- 每个热点标注区域类型、当前占用和基础计分提示。
- 玩家选择普通随从、可用特殊角色或跳过。
- 长按区域可以查看完整连接范围和控制权。

### 4.5 计分与结束回合

- 大屏沿完成区域高亮，逐项展示分数来源。
- 手机显示该玩家获得或未获得分数的原因。
- 角色归还动画完成后，主机进入下一回合。

## 5. 非当前玩家

非当前玩家可以：

- 查看自己的剩余角色和公开分数
- 阅读已启用规则
- 查看公共地图和历史计分
- 处理扩展要求的秘密或同时选择
- 设置本地音量、振动和无障碍选项

非当前玩家不能移动地块、替当前玩家确认或读取未授权的私人信息。

## 6. 4K 公共画面

### 6.1 常驻信息

- 当前玩家和回合阶段
- 公共得分排名
- 剩余地块数量
- 主机、手机和网络状态
- 简洁的全局小地图或地图边界提示

### 6.2 镜头行为

- 放置阶段自动聚焦预览位置。
- 计分阶段框选完整连接区域。
- 回合切换时保持地图方向稳定，避免眩晕。
- 提供全局概览、当前区域和自由观察三种镜头模式。
- 玩家手动操作镜头后，在明确事件发生时才自动接管。

### 6.3 可读性

- 按 2–3 米观看距离设计文字和图标。
- 不把颜色作为唯一识别方式。
- 为电视过扫描保留安全边距。
- 静态高亮元素定期轻微变化或降低亮度，减少 OLED 风险。
- 3D 场景可动态降分辨率，UI 和区域轮廓保持清晰。

## 7. Windows 降级操作

没有手机或手机断线时，可以使用：

- 鼠标左键选择与确认
- 鼠标滚轮缩放
- 中键或空格拖动平移
- 右键拖动旋转镜头
- `Q` / `E` 旋转地块
- `Enter` 确认
- `Esc` 取消

房主可以临时接管任意本地席位，但接管行为必须写入对局日志。

## 8. 防误操作

- 地块放置使用“选择 → 预览 → 确认”。
- 角色放置使用独立确认步骤。
- 规则主机接受命令前再次验证回合、席位、坐标和旋转。
- 确认前可以取消；主机确认并广播后不可撤销。
- 手机基础触控目标不小于约 44–48 dp。
- 危险的房主管理操作需要二次确认。

## 9. 隐私和同时选择

扩展可能加入秘密纹章、竞价、任务或私人资源。系统必须：

- 仅向所属手机发送私人数据。
- 大屏只显示等待状态，不显示具体选择。
- 所有参与者提交后由主机统一揭示。
- 录像分别记录权威结果与按观看权限过滤的展示结果。

## 10. 断线体验

- 席位与设备分离，设备断线不删除席位。
- 玩家重新扫码并持有席位令牌时恢复原身份。
- 当前玩家断线时进入房间配置的宽限状态。
- 房主可选择继续等待、PC 接管或 AI 托管。
- 网络恢复后，手机先加载主机快照，再继续接收增量事件。

## 11. AR 预留

AR 是普通 3D 表现的可选观察方式：

- AR Lite：单设备将完成地图放在真实桌面上观赏和拍摄。
- Shared AR：多部手机通过公共定位标记看到同一空间地图。
- Interactive AR：在现实空间中选择候选位置，但最终确认仍在固定 UI 中完成。

规则层只识别逻辑网格。AR 丢失追踪、比例变化或定位漂移不得影响合法性和对局状态。

## 12. 无障碍与舒适性

- 字体缩放和高对比度模式
- 色觉安全的图形与纹理区分
- 字幕和音效可视提示
- 减少动画和关闭镜头自动移动
- 关闭振动或降低振动强度
- 左右手控制布局
- 手机横竖屏的最低可用布局

## 13. 交互验收

- 新玩家不阅读说明也能完成基础地块与随从放置。
- 主机拒绝操作时，玩家能知道具体原因。
- 手机掉线重连后不需要重新选择玩家颜色或重建房间。
- 大屏在地图较大时仍能清晰指示当前操作区域。
- 无手机情况下，一整局基础游戏仍可完成。
- 关闭全部非必要动画后，所有操作和计分仍然清楚。
