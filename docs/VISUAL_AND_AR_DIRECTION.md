# 视觉、素材与 AR 方向

- 文档版本：0.1
- 当前状态：方向约束与扩展接口
- 优先级：低于规则正确性、局域网稳定性和交互可读性

## 1. 视觉目标

推荐采用原创的“中世纪手工微缩沙盘”风格：地图像一套不断生长的精致模型，而不是平铺官方纸质地块。风格需要兼顾：

- 从 2–3 米外辨认道路、城市、田野和角色
- 在普通 Windows 电脑上稳定输出到 4K 电视
- 模型和材质能够程序化组合大量地块
- 后续可以自然进入 AR 桌面展示
- 不复刻官方插画、米宝造型、包装或品牌标识

## 2. 素材原则

- 地形、建筑、角色、图标、动画、纹理和音效采用项目原创或为项目生成的素材。
- 每项素材记录生成方式、作者、日期、版本和使用许可。
- 必要的字体、运行库和工具可以使用许可清晰的开源资源。
- 不使用来源不明的素材包。
- 规则地块 ID 与视觉资产 ID 分离，替换美术不能修改拓扑或存档。
- 若未来公开发行，所有素材在发布前完成权利和相似性复核。

## 3. 地块视觉结构

每块地块的表现可以拆为：

1. 逻辑底座：统一网格尺寸和高度基准。
2. 地貌表面：草地、泥土、河床和道路。
3. 建筑层：城墙、房屋、修道院、桥梁等。
4. 装饰层：树木、庄稼、石头、动物和烟雾。
5. 规则标志层：盾徽、商品或扩展符号的清晰提示。
6. 交互层：候选轮廓、连接端口、控制权和计分高亮。

装饰物不得遮挡规则边界。低质量模式可以减少装饰，但不能移除规则标志。

## 4. 地形融合

地块放置后允许视觉上消除方格接缝，但必须保持离散逻辑网格：

- 相邻高度边缘平滑过渡
- 草地和土壤材质混合
- 道路纹理延伸并连接
- 河岸和水面连续
- 植被在边界附近渐入
- 城墙和道路节点使用连接模型

融合仅影响渲染。碰撞、区域、合法性和计分仍来自地块拓扑。

## 5. 放置表现

推荐的完整表现序列：

1. 地块从公共牌堆升起。
2. 合法候选位置出现克制的空间轮廓。
3. 手机选择位置后，大屏聚焦半透明预览。
4. 旋转时端口吸附并突出匹配关系。
5. 确认后地块轻微落下，产生尘土、草叶或石屑。
6. 道路和地表完成边缘融合。
7. 建筑按地块类型快速组装或升起。
8. 完成区域沿完整拓扑高亮并进入计分表现。

首阶段可以只实现半透明预览、短暂落下和区域描边。

## 6. 规则事件与表现

表现层订阅语义事件，例如：

| 规则事件 | 可选表现 |
|---|---|
| `TileDrawn` | 牌堆抽取和地块翻面 |
| `TilePlaced` | 落下、尘土和边缘融合 |
| `FeatureConnected` | 道路、城墙或河流连接脉冲 |
| `MeeplePlaced` | 角色进入和职业姿态 |
| `FeatureCompleted` | 完整区域描边、建筑完成演出 |
| `PointsAwarded` | 分数轨迹和得分来源标签 |
| `MeepleReturned` | 角色返回玩家供应 |
| `GameEnded` | 全图展示和获胜者演出 |

没有表现订阅者时，规则事件仍必须正常完成。

## 7. 4K 画质层级

### 低档

- 较低 3D 内部分辨率
- 简单阴影和少量植被
- 关闭景深、体积效果和复杂粒子
- UI、规则轮廓和文字保持清晰

### 中档

- 动态阴影
- 中等植被与建筑细节
- 基础天气和地形融合

### 高档

- 高分辨率材质
- 更密集的植被和环境动画
- 体积光、景深和高级粒子
- 更远的地图细节和摄影模式

集成显卡目标是稳定可玩的 30 FPS，合适的独立显卡目标是 60 FPS。规则主机更新不依赖渲染帧率。

## 8. 镜头与信息可读性

- 战略俯视角用于放置和连接确认。
- 倾斜微缩景观角用于观赏和完成演出。
- 自动镜头只在明确阶段切换，并可关闭。
- 计分高亮覆盖完整逻辑区域，而不是凭视觉估计。
- 地图很大时使用局部聚焦和小地图，不能强行把全图缩到不可读。

## 9. 声音

- 每种规则事件具有稳定的声音事件 ID。
- 道路、城市、修道院和田野使用可区分的计分提示。
- 声音不是唯一反馈；所有声音事件均有视觉对应。
- 支持分别调整音乐、环境、界面和语音音量。
- 提供静音模式，静音不影响回合节奏。

## 10. AR 分级

### 10.1 AR Lite

- 将当前或完成地图放到真实桌面。
- 支持缩放、旋转、截图和录像。
- 不承担正式规则输入。

### 10.2 Shared AR

- Windows 大屏发布公共定位标记。
- 多部手机对齐同一地图原点。
- 每部手机从自己的座位查看同一场景。
- 网络只同步逻辑状态和锚点变换，不传输摄像头画面。

### 10.3 Interactive AR

- 点击现实空间中的候选位置进行预览。
- 旋转和最终确认仍提供固定屏幕按钮。
- 权威主机将 AR 命中结果转换为整数网格后重新验证。

## 11. AR 安全边界

- AR 完全可选。
- 不支持 AR 的玩家可以加入同一局。
- 追踪丢失只影响本机显示。
- AR 坐标、浮点误差和摄像头帧不得进入规则日志。
- 不要求玩家长时间举着手机才能游戏。
- 公共大屏仍是聚会的主要视觉焦点。

## 12. 素材完成定义

一项视觉素材进入正式版本前需要：

1. 通过来源和许可检查。
2. 绑定稳定的视觉资产 ID。
3. 在目标观看距离下清晰可辨。
4. 通过低、中、高画质测试。
5. 不遮挡区域边界和规则符号。
6. 在关闭该素材时仍能完成规则操作。
7. 在普通 3D 和未来 AR 比例下表现合理。
